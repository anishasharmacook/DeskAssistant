# DeskAssistant

I am coding a touchscreen organiser built for the M5Stack Tab5 using UIFlow 2.

## Features

- Live clock and date
- Home dashboard
- Upcoming reminders
- To-do list
- Add new tasks
- Add reminders
- Touchscreen menu interface

## Hardware

- M5Stack Tab5

## Software

- UIFlow 2

## Project Structure

The application contains two main sections:

### Home

Displays:

- Current time
- Current date
- Upcoming reminders
- Number of outstanding tasks

### Menu

Allows the user to:

- Add a to-do item
- View to-do items
- Add a reminder
- View reminders

## Running the Project

1. Open UIFlow 2.
2. Select M5Stack Tab5.
3. Import `M5Stack-Organiser.m5f2`.
4. Connect the Tab5.
5. Run the project.
